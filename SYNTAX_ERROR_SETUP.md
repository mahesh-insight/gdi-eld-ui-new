# VS Code Extensions for Real-time Error Detection

Install these VS Code extensions for immediate syntax error visibility:

## Essential Extensions:
1. **ES7+ React/Redux/React-Native snippets** - `dsznajder.es7-react-js-snippets`
2. **ESLint** - `dbaeumer.vscode-eslint`
3. **Prettier - Code formatter** - `esbenp.prettier-vscode`
4. **JavaScript (ES6) code snippets** - `xabikos.JavaScriptSnippets`
5. **Bracket Pair Colorizer** - `CoenraadS.bracket-pair-colorizer-2`

## Install via VS Code:
- Open VS Code
- Go to Extensions (Ctrl+Shift+X)
- Search for "ESLint" and install
- Search for "Prettier" and install

## Or install via command line:
```bash
code --install-extension dbaeumer.vscode-eslint
code --install-extension esbenp.prettier-vscode
```

These extensions will show syntax errors with red squiggly lines in real-time as you type.
